## Highlights & New Features

### 1. Just-in-Time (JIT) / RFC 9396 Step-Up Authorization Guards (`lumoauth_fastmcp.checks`, `lumoauth_fastmcp.policy`, `lumoauth_fastmcp.provider`)

Sensitive MCP tools can now require task-bound RFC 9396 Rich Authorization Requests (`authorization_details`) and emit structured step-up challenges when a human approval is missing:

- Added `require_jit()`, `ensure_jit()`, `InsufficientAuthorizationDetailsError`, `build_authorization_detail()`, `authorization_detail_covered()`, and `missing_authorization_details()` (`src/lumoauth_fastmcp/checks.py`):
  - `require_jit(type_or_details, actions=..., locations=..., identifier=...)` guards `@mcp.tool(auth=...)` declaratively.
  - `ensure_jit(type_or_details, actions=..., locations=..., identifier=...)` validates runtime argument-bound requirements inside a tool body.
  - `InsufficientAuthorizationDetailsError` formats `insufficient_authorization_details` errors with `authorization_details_hint` and Base64-encoded `Insufficient-Authorization-Details` headers for self-escalating agents.
- Extended `LumoToolPolicy` (`src/lumoauth_fastmcp/policy.py`) with a `jit={tool_name: spec}` parameter so tools remain visible in `tools/list` while enforcing step-up approval on `tools/call`.
- Extended `LumoAuthProvider` (`src/lumoauth_fastmcp/provider.py`) and `LumoAuthHttpMiddleware` (`src/lumoauth_fastmcp/_asgi.py`) to accept and verify accompanying `X-LumoAuth-Jit-Token` headers against the organization JWKS and caller subject, merging verified `authorization_details` onto `current_caller()`, and rewriting `403` `WWW-Authenticate` and `Insufficient-Authorization-Details` response headers.

```python
from lumoauth_fastmcp import LumoAuthProvider, ensure_jit, require_jit

auth = LumoAuthProvider()

@mcp.tool(auth=require_jit("payment_initiation", actions=["refund"]))
def refund(invoice_id: str) -> str:
    ensure_jit("payment_initiation", actions=["refund"], identifier=invoice_id)
    return f"Refunded {invoice_id}"
```

### 2. Token Vault Helper for Outbound SaaS APIs (`lumoauth_fastmcp.vault`, `lumoauth_fastmcp.provider`)

MCP tools can now mint short-lived upstream OAuth access tokens (e.g., GitHub, Slack, Jira, Google Workspace) from LumoAuth's Token Vault, automatically scoped to the active MCP caller:

- Added `LumoVaultClient`, `VaultToken`, and `resolve_vault_user_id()` (`src/lumoauth_fastmcp/vault.py`):
  - `LumoVaultClient.get_token(connection_id, user_id=..., caller=..., traceparent=...)` and `list_connections()` call `/orgs/{org}/api/v1/agents/me/connections/{connection_id}/token` with automatic in-memory caching (30s safety buffer before `expires_at`) and 401 token refresh retry.
  - Automatic caller delegation: when `current_caller()` is a human user (`not caller.is_agent`) or a user-delegated agent (`caller.is_delegated`), `user_id` defaults to `caller.sub`.
  - `VaultToken.headers()` helper returning `{"Authorization": "<token_type> <access_token>"}`.
- Extended `LumoAuthProvider` (`src/lumoauth_fastmcp/provider.py`) with `agent_token` (`LUMOAUTH_AGENT_TOKEN`), `auth.vault(**options)`, and `auth.vault_token(connection_id, ...)`.

```python
@mcp.tool
def create_github_issue(repo: str, title: str) -> dict:
    gh_token = auth.vault_token("conn_github_prod")
    response = requests.post(
        f"https://api.github.com/repos/{repo}/issues",
        headers={**gh_token.headers(), "Accept": "application/vnd.github+json"},
        json={"title": title},
        timeout=10,
    )
    response.raise_for_status()
    return response.json()
```

### 3. W3C `traceparent` Distributed Trace Propagation (`lumoauth_fastmcp._asgi`, `lumoauth_fastmcp.policy`, `lumoauth_fastmcp.vault`)

- Added `parse_traceparent()`, `current_traceparent()`, and `current_trace_id()` (`src/lumoauth_fastmcp/_asgi.py`) to validate incoming W3C `traceparent` HTTP headers (`00-<trace-id>-<span-id>-<flags>`) and attach `traceparent` and `trace_id` to `current_caller()`.
- Automatically forwarded `traceparent` on `LumoToolPolicy` (`mcp.authorize_tool`) and `LumoVaultClient` requests to correlate MCP tool decisions and Token Vault calls in LumoAuth's audit log.
